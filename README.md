# Tarmeez

A client-side web application built with vanilla JavaScript, demonstrating async operations, DOM manipulation, and user interaction.

## ✨ Features
- Simulated login/logout with session persistence
- Fetch and display posts from JSONPlaceholder API
- Loader toggle during API requests
- Responsive UI with Bootstrap

## 🛠️ Technologies
- HTML5 / CSS3
- JavaScript (ES6+)
- Axios
- Bootstrap 5
- Local Storage

## ▶️ How to Run
1. Clone the repo
2. Open `index.html` in your browser

> Note: Internet connection required for API calls.
